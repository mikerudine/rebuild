Методологія

Звідки цифри, як ми працюємо з SDMX і чого поки не вистачає в відкритих даних.

Держстат SDMX

  • Каталог dataflow: https://stat.gov.ua/sdmx/workspaces/default:integration/registry/sdmx/2.1/dataflow/all/all/latest (125 потоків станом на перевірку 2026-10-11).
  • Доступність регіонів: /availableconstraint/<DF>/all/all/REGION.
  • Дані: /data/<DF>/<key>?startPeriod=YYYY. Ключ не може починатися з «.» — спочатку код показника (ACT_ENTRP, REG_LEG_ENT тощо).
  • Фільтр c[REGION]= ігнорується API; CSV через Accept часто дає 404 — використовуємо XML.

Магазини мереж (OSM) та HoReCa

  • Магазини мереж: Geofabrik OSM PBF (1 січня 2021–2026), зіставлення shop=* з брендами; офіційні локатори ATB/Silpo/Fora/Novus/Sim23 для повноти; ATB скориговано за прес-релізами (rau.ua, allretail.ua). CSV: oblast_store_counts.csv, atb_corrected_oblast_change.csv.
  • Заклади харчування: Derzhstat KVED секція I на рівні області; OSM amenity через ohsome (1 січня). CSV: oblast_horeca_compare.csv, derzhstat_kved_I_oblast_growth.csv, osm_hromada_food_counts.csv.
  • Пошта і посилки: Nova Poshta API getWarehouses (UUIDv1 Ref → дата створення точки); прив’язка до громади bounds.pkl; злиття з рейтингом зростання бізнес-реєстру. Національні цифри — прес Nova Poshta 2025 (522 млн посилок) та НКЕК форма 3-П. CSV: hromada_growth_vs_np.csv, np_hromada_counts.csv (findings 2026-10-11).

Рейтинг громад і work.ua

  • Kaggle: rebuild-ukraine-hromada-growth — таблиці зростання юросіб/ФОП 2021→2025, зони, композит (джерело: SDMX бізнес-реєстр).
  • work.ua/stat — місячні медіанні зарплати в оголошеннях і кількість вакансій по містах (public/data/workua_city_monthly.csv).

Інші джерела (кейси)

  • Державні та регіональні ЗМІ, сайти громад, матеріали SHABO — з прямими посиланнями на сторінках кейсів.
  • api.openbudget.gov.ua — очікуване джерело бюджетів громад; з інфраструктури збірки не перевірено (можливе гео-обмеження). Не використовуємо цифри бюджету без успішної верифікації.
  • decentralization.gov.ua, Prozorro, Opendatabot — кандидати для наступних ітерацій.

Обмеження

  • Населення села/громади у SDMX не знайдено; DF_POPULATION_STRUCTURE — рівень області (1989–2025).
  • Війна: дані після 2022 частково без тимчасово окупованих територій (примітки в metadata наборів).
  • Реформа 2020: зміни меж громад; коди КАТОТТГ vs історичні КОАТУУ.
  • Кожен графік на сайті має JSON з source, fetched_at і URL запиту; без джерела цифра не публікується.

Пайплайн збірки
