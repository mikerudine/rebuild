Магазини мереж

Зміни магазинів мереж ATB, Silpo, Fora, Novus, Sim23 тощо за зрізами OpenStreetMap (1 січня 2021 → 2026) та скориговані оцінки для ATB за офіційними списками. Зростання OSM частково відображає доповнення мап, а не лише відкриття.

Застереження

  • Зростання OSM = відкриття + наздоганання маперів; для ATB на 2026 повнота ~99%, для Sim23 — ~34%.
  • Крим, Севастополь, Донецьк, Херсон, Луганськ: окуповані території, теги OSM змінювались — не інтерпретуйте як чисті закриття/відкриття.
  • Лише ~500 громад мають хоч один магазин мережі в OSM; слабкий зв’язок із CAGR юросіб (Spearman 0.14).

Джерела: Geofabrik OSM, OpenStreetMap contributors, ATB/Silpo/Fora/Novus/Sim23 locators (деталі: findings 2026-10-11).
